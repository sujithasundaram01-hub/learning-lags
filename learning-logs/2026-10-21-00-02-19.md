### Topic: Understanding Python List Comprehensions

List comprehensions provide a concise way to create lists in Python. They are often faster and more readable than traditional `for` loops when you need to transform or filter data.

#### Key Learning Points:
* **Syntax:** `[expression for item in iterable if condition]`
* **Efficiency:** They are optimized for the Python interpreter compared to appending items in a standard loop.
* **Readability:** When used properly, they turn 3–4 lines of code into a single, declarative line.
* **Limitation:** Avoid complex, nested comprehensions as they can become difficult to debug and read.

#### Practical Example:
Filtering even numbers and squaring them from a range of 1 to 10:

```python
# Traditional approach
squares = []
for x in range(1, 11):
    if x % 2 == 0:
        squares.append(x**2)

# List comprehension approach
squares_lc = [x**2 for x in range(1, 11) if x % 2 == 0]

print(squares_lc) 
# Output: [4, 16, 36, 64, 100]
```
