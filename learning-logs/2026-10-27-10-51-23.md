### Topic: Mastering Python List Comprehensions

List comprehensions provide a concise way to create lists in Python. They are often faster and more readable than traditional `for` loops when you need to transform or filter data.

#### Key Learning Points:
*   **Syntax:** `[expression for item in iterable if condition]`
*   **Readability:** They allow you to reduce 3-4 lines of loop code into a single, clean line.
*   **Performance:** Generally faster than `append()` calls inside a standard loop because they are optimized for the Python interpreter.
*   **Conditionals:** You can include `if` statements to filter elements and even `if-else` blocks for more complex transformations.

#### Practical Example: Filtering and Transforming Data
Imagine you have a list of numbers, and you want to create a new list containing the squares of only the even numbers.

**Using a standard loop:**
```python
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = []
for n in numbers:
    if n % 2 == 0:
        squared_evens.append(n**2)
```

**Using List Comprehension (Professional approach):**
```python
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = [n**2 for n in numbers if n % 2 == 0]

print(squared_evens)  # Output: [4, 16, 36]
```
