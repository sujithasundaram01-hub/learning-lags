### Topic: Mastering Python List Comprehensions

List comprehensions provide a concise way to create lists in Python. They are often faster and more readable than traditional `for` loops when you need to transform or filter data.

#### Key Learning Points:
*   **Syntax:** `[expression for item in iterable if condition]`
*   **Readability:** They turn multi-line loops into a single, elegant line.
*   **Performance:** They are generally faster than using `.append()` in a loop because they are optimized for the Python interpreter.
*   **Filtering:** You can include an `if` statement to select only specific elements.

#### Practical Code Example:
Imagine you want to square only the even numbers from a list of integers.

**Traditional Approach:**
```python
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = []
for n in numbers:
    if n % 2 == 0:
        squared_evens.append(n**2)
# Result: [4, 16, 36]
```

**List Comprehension Approach:**
```python
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = [n**2 for n in numbers if n % 2 == 0]
print(squared_evens) 
# Result: [4, 16, 36]
```
