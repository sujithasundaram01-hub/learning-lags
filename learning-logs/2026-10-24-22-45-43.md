### Topic: Mastering Python List Comprehensions

List comprehensions provide a concise way to create lists in Python. They are often faster and more readable than traditional `for` loops when you need to transform or filter data.

---

### Key Learning Points
1.  **Syntax:** `[expression for item in iterable if condition]`
2.  **Efficiency:** They are implemented in C under the hood, making them faster than manual `.append()` operations inside a loop.
3.  **Readability:** They allow you to collapse multi-line loops into a single, declarative line of code.
4.  **Constraints:** Avoid overly complex comprehensions (e.g., nested ones) as they can become difficult to debug and read.

---

### Practical Example

**Problem:** You have a list of numbers, and you want to create a new list containing only the squares of the even numbers.

**Using a standard loop:**
```python
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = []
for n in numbers:
    if n % 2 == 0:
        squared_evens.append(n**2)
# Result: [4, 16, 36]
```

**Using List Comprehension:**
```python
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = [n**2 for n in numbers if n % 2 == 0]
print(squared_evens) 
# Result: [4, 16, 36]
```
