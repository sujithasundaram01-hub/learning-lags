### Day 1: Mastering the Two-Pointers Technique (DSA Fundamentals)

The **Two-Pointers Technique** is one of the most efficient algorithmic patterns used to solve problems involving arrays or strings. Instead of using nested loops (which often lead to $O(n^2)$ time complexity), we use two indices (pointers) that move through the data structure simultaneously, typically reducing the complexity to $O(n)$.

#### 💡 Key Learning Points
1.  **Efficiency:** It optimizes performance by avoiding redundant calculations.
2.  **Pointer Directions:** Pointers can move toward each other (opposite ends) or in the same direction (slow and fast pointers).
3.  **Prerequisites:** For most "opposite end" problems, the array must be **sorted**.
4.  **Common Use Cases:** Finding pairs with a specific sum, reversing an array, or detecting cycles in a linked list.

#### 💻 Practical Code Example: Target Sum Pair
*Problem: Given a sorted array, find if there exists a pair of numbers that sum up to a specific target.*

```python
def has_pair_with_sum(arr, target):
    # Initialize two pointers
    left = 0
    right = len(arr) - 1

    while left < right:
        current_sum = arr[left] + arr[right]
        
        if current_sum == target:
            return (arr[left], arr[right]) # Pair found
        elif current_sum < target:
            left += 1  # Need a larger sum, move the left pointer forward
        else:
            right -= 1 # Need a smaller sum, move the right pointer backward
            
    return None

# Test the function
sorted_numbers = [1, 2, 4, 6, 8, 10, 15]
target_val = 14

result = has_pair_with_sum(sorted_numbers, target_val)
print(f"Pair for target {target_val}: {result}") 
# Output: (4, 10)
```
