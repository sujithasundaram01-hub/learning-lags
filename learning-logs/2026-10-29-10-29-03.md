# Day 1: Mastering Asynchronous JavaScript (Promises & Async/Await)

### 🌟 Introduction
In modern web development, JavaScript often needs to perform tasks that take time, such as fetching data from an API, reading a file, or waiting for a timer. Because JavaScript is single-threaded, if it waited for these tasks to finish before moving to the next line, the entire application would freeze. **Promises** and **Async/Await** allow us to handle these "background" tasks without blocking the main execution.

---

### 🔑 Key Learning Points
1.  **The Promise Object:** Represents a value that may be available now, in the future, or never. It has three states: *Pending*, *Fulfilled* (success), and *Rejected* (failure).
2.  **The `await` Keyword:** It pauses the execution of an `async` function until the Promise is settled, making the code look and behave more like synchronous code.
3.  **The `async` Keyword:** Used to define a function that always returns a Promise.
4.  **Error Handling:** Instead of using `.catch()`, we use `try...catch` blocks within async functions to handle potential errors cleanly.

---

### 💻 Practical Code Example: Simulating an API Call

This example demonstrates how to fetch user data using the modern `async/await` syntax.

```javascript
// A function that simulates fetching data from a database/API
const fetchUserData = (userId) => {
    return new Promise((resolve, reject) => {
        console.log("Fetching data from server...");
        
        setTimeout(() => {
            const users = {
                1: { name: "Alice", role: "Developer" },
                2: { name: "Bob", role: "Designer" }
            };

            const user = users[userId];

            if (user) {
                resolve(user); // Success
            } else {
                reject("Error: User not found!"); // Failure
            }
        }, 2000); // Simulates a 2-second delay
    });
};

// Using Async/Await to handle the Promise
async function displayUser(id) {
    try {
        const data = await fetchUserData(id);
        console.log(`User Profile: ${data.name} - ${data.role}`);
    } catch (error) {
        console.error(error);
    } finally {
        console.log("Operation complete.");
    }
}

// Execution
displayUser(1); // Successful case
displayUser(99); // Error case
```
