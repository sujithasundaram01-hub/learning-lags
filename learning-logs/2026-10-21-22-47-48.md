### Topic: Understanding Big O Notation in DSA

**Explanation:**
Big O notation is the standard mathematical language used to describe the efficiency of an algorithm. It measures how the runtime or space requirements of your code grow as the size of the input data ($n$) increases. It’s not about measuring time in seconds, but about measuring the "rate of growth."

**Key Learning Points:**
*   **O(1) - Constant Time:** Operations take the same amount of time regardless of input size (e.g., accessing an array index).
*   **O(n) - Linear Time:** The runtime increases proportionally to the input size (e.g., looping through a list once).
*   **O(n²) - Quadratic Time:** The runtime increases proportionally to the square of the input size (e.g., nested loops).
*   **Focus:** In coding interviews, recruiters look for your ability to optimize solutions from $O(n^2)$ down to $O(n \log n)$ or $O(n)$.

**Practical Code Example (Python):**

```python
# O(n) - Linear Time
def find_max(arr):
    max_val = arr[0] # O(1)
    for num in arr:  # O(n)
        if num > max_val:
            max_val = num
    return max_val

# O(n^2) - Quadratic Time (Nested loops)
def has_duplicates(arr):
    for i in range(len(arr)):        # O(n)
        for j in range(i + 1, len(arr)): # O(n)
            if arr[i] == arr[j]:
                return True
    return False
```
