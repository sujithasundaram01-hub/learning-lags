### Topic: Understanding Python List Comprehensions

List comprehensions provide a concise way to create lists in Python. They are often faster and more readable than traditional `for` loops when you need to transform or filter data.

#### Key Learning Points:
* **Syntax:** `[expression for item in iterable if condition]`
* **Efficiency:** They are optimized for the Python interpreter compared to `.append()` calls inside a loop.
* **Readability:** When used properly, they turn multi-line loops into a single, declarative line of code.
* **Limitations:** Avoid complex nested comprehensions, as they can become difficult to debug and maintain.

#### Practical Code Example:
Instead of writing a standard loop to filter even numbers and square them, you can do it in one line:

```python
# Traditional approach
numbers = [1, 2, 3, 4, 5, 6]
squared_evens = []
for n in numbers:
    if n % 2 == 0:
        squared_evens.append(n**2)

# Using List Comprehension
squared_evens_lc = [n**2 for n in numbers if n % 2 == 0]

print(f"Original: {numbers}")
print(f"Result: {squared_evens_lc}")
```
