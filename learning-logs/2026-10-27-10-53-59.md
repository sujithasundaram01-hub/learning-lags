# Python Dictionary Comprehensions: Clean & Efficient Data Mapping

### Explanation
In Python, **Dictionary Comprehension** is a concise and elegant way to create dictionaries from iterables. Instead of using a traditional `for` loop to populate a dictionary, you can do it in a single line. This technique is not only more "Pythonic" but often faster in terms of execution. It is a vital skill for writing clean, professional code that is easy for teammates to read.

### Key Learning Points
*   **Syntax:** `{key_expression: value_expression for item in iterable if condition}`.
*   **Efficiency:** Reduces the number of lines of code and utilizes Python's internal optimizations for building collections.
*   **Transformation:** Useful for modifying keys or values (e.g., converting all keys to lowercase).
*   **Filtering:** You can add an `if` statement at the end to include only specific items in your new dictionary.

### Practical Code Example
Imagine you have a list of products with their prices in USD, and you want to create a dictionary that only includes products over $50, converted to a specific format.

```python
# List of tuples (Product Name, Price in USD)
products = [("Laptop", 1200), ("Mouse", 25), ("Monitor", 200), ("USB Cable", 15)]

# Traditional Method
expensive_products_old = {}
for name, price in products:
    if price > 50:
        expensive_products_old[name] = f"${price}"

# Dictionary Comprehension Method
expensive_products_new = {name: f"${price}" for name, price in products if price > 50}

print(expensive_products_new)
# Output: {'Laptop': '$1200', 'Monitor': '$200'}
```
